# تماشای دونفره — Watch Party (Peer-to-Peer)

یک اپ ساده‌ی «سینمای خصوصی دو نفره»: یک نفر لینک مستقیم ویدیو (mp4/webm/HLS) را می‌دهد،
اتاق می‌سازد، کد/لینک/QR را برای نفر دوم می‌فرستد و پخش بین دو مرورگر همگام می‌شود —
بدون بک‌اند و بدون آپلود فایل روی هیچ سروری.

## چطور کار می‌کند

- **هیچ سروری برای ویدیو نیست.** هر مرورگر مستقیماً از همان لینکی که وارد کردی ویدیو را پخش می‌کند.
- **همگام‌سازی با WebRTC (Peer-to-Peer)** انجام می‌شود، با کتابخانه‌ی
  [PeerJS](https://peerjs.com/). PeerJS فقط برای «دست دادن اولیه»‌ی دو مرورگر
  از یک سرور سیگنالینگ رایگان و عمومی (`0.peerjs.com`) استفاده می‌کند؛ بعد از وصل شدن،
  داده (پخش/مکث/زمان/چت) مستقیم بین دو مرورگر رد و بدل می‌شود.
- کد اتاق همان **Peer ID** میزبان است؛ نفر دوم با همان کد مستقیماً به مرورگر میزبان وصل می‌شود.
- زیرنویس (`.srt` یا `.vtt`) در خود مرورگر پردازش و به‌صورت `<track>` به ویدیو اضافه می‌شود.
- میکروفون هم یک تماس صوتی یک‌طرفه‌ی جدا روی همان اتصال WebRTC است — اختیاری و پیش‌فرض خاموش.

هیچ داده‌ای (نه ویدیو، نه صدا) از سرور شخص ثالثی عبور یا در جایی ذخیره نمی‌شود؛ فقط
سیگنالینگ اولیه از PeerJS رد می‌شود.

## اجرای محلی (تست سریع)

چون از `fetch`/ES features استفاده شده، باید از یک وب‌سرور ساده اجرا بشه (نه باز کردن مستقیم فایل):

```bash
cd freemovie
python3 -m http.server 8080
# یا: npx serve .
```

بعد در دو تب/دو مرورگر جدا `http://localhost:8080` را باز کن، یکی اتاق بسازد و دیگری با کد وصل شود.

> نکته: چون هر دو از یک کامپیوتر تست می‌کنی، WebRTC معمولاً بدون مشکل روی `localhost` کار می‌کند.
> برای تست واقعی بین دو دستگاه مختلف، باید سایت روی HTTPS باشد (GitHub Pages این را رایگان می‌دهد).

## دیپلوی روی GitHub Pages (رایگان)

۱. یک ریپوی جدید در گیت‌هاب بساز (مثلاً `watch-party`).
۲. فایل‌های این پوشه (`index.html`, `css/`, `js/`, `README.md`) را داخل ریپو push کن:

```bash
git init
git add .
git commit -m "اولیه: تماشای دونفره"
git branch -M main
git remote add origin https://github.com/USERNAME/watch-party.git
git push -u origin main
```

۳. در گیت‌هاب برو به **Settings → Pages**.
۴. زیر «Build and deployment» گزینه‌ی **Source** را روی **Deploy from a branch** بگذار،
   Branch را `main` و پوشه را `/ (root)` انتخاب کن و **Save** بزن.
۵. بعد از حدود ۱ تا ۲ دقیقه، سایت روی آدرسی مثل زیر بالا می‌آید:

```
https://USERNAME.github.io/watch-party/
```

## وصل کردن دامنه‌ی اختصاصی خودت

اگر یک دامنه (مثلاً `freemovie.com`) داری:

۱. داخل ریپو یک فایل به اسم `CNAME` (بدون پسوند) بساز و فقط دامنه را داخلش بنویس:
   ```
   freemovie.com
   ```
   (یا اگر می‌خوای روی ساب‌دامین باشه: `watch.freemovie.com`)

۲. داخل پنل مدیریت دامنه‌ات (جایی که دامنه رو خریدی)، یکی از این دو حالت را تنظیم کن:
   - **دامنه‌ی ریشه (apex, مثل `freemovie.com`):** چهار رکورد **A** بساز که به آی‌پی‌های
     گیت‌هاب اشاره کنند:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - **ساب‌دامین (مثل `watch.freemovie.com`):** یک رکورد **CNAME** بساز که به
     `USERNAME.github.io` اشاره کند.

۳. دوباره برو **Settings → Pages**، دامنه‌ی خودت را در فیلد **Custom domain** وارد کن و Save بزن.
   بعد از چند دقیقه تا چند ساعت (به خاطر انتشار DNS)، گزینه‌ی **Enforce HTTPS** را هم فعال کن —
   WebRTC/میکروفون بدون HTTPS در اکثر مرورگرها کار نمی‌کند.

## محدودیت‌ها و نکات فنی مهم

- **اتصال دو نفره:** طراحی فعلی برای دقیقاً ۲ نفر در هر اتاق است (host + یک guest).
- **NAT سخت‌گیرانه:** در برخی شبکه‌ها (VPN های خاص، فایروال‌های سازمانی) اتصال مستقیم
  WebRTC ممکن است برقرار نشود چون این پروژه فقط از STUN عمومی پیفالت PeerJS استفاده می‌کند
  و TURN اختصاصی ندارد. اگر لازم شد، می‌شه یک سرور TURN (مثلاً از Twilio یا metered.ca) اضافه کرد.
- **لینک‌های ویدیو:** لینک باید مستقیماً قابل پخش در `<video>` باشد (CORS باز، فرمت mp4/webm/HLS).
  لینک‌هایی که نیاز به لاگین یا هدر خاص دارند کار نمی‌کنند.
- **حریم خصوصی:** فقط باید از ویدیوهایی استفاده کنی که مالکش هستی یا اجازه‌ی پخش داری؛
  این ابزار صرفاً یک لوله‌ی همگام‌سازی است و مسئولیت محتوای لینک با کاربر است.

## ساختار فایل‌ها

```
freemovie/
├── index.html          همه‌ی صفحات (لندینگ، ویزارد، لابی، اتاق تماشا)
├── css/style.css        استایل تیره/طلایی، ریسپانسیو
├── js/peer.js            اتصال WebRTC/PeerJS و پروتکل پیام‌ها
├── js/subtitles.js       تبدیل srt به vtt
└── js/app.js              منطق اصلی اپ و رابط کاربری
```
